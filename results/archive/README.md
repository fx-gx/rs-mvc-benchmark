1. **BLAS 线程数未固定** —— 实测同配置换线程数能差 5.9 个 ACC 点

   两种读出协议：24 条 n_init=3 + 11 条 n_init=10。已修。

Salinas 在旧协议下的结论（λ=1 γ=1 最优、端到端 +0.1104）**未被推翻**，
但绝对值已作废，需在统一协议下重跑。
